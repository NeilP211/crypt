# HNSW Benchmark Report

_Generated by `cargo run --release --bin hnsw-report`. Recall is measured against brute-force exact kNN — the true nearest neighbors — which is a stricter reference than any approximate library. Data is clustered synthetic (Gaussian mixture), modeling the cluster structure of real CLIP image embeddings; uniform-random vectors are an adversarial worst case no ANN benchmark uses._
